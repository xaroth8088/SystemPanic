# Tooling memory

- `verify.py`: bounded samples of all installed complete endless solo runs (12 cleared levels by default), verifying +1 initial enemy per level and continued play, plus UI screenshots and asset hashes. The QA stopping point is not a game finish.
- `compatibility.py`: stability checks for every pilot/enemy/weapon/obstacle gameplay mix (12^4 with the shipped set), plus rendering/streaming every background/music pair (12^2). --require-clear is an optional balance probe. The report distinguishes these checks from the full six-channel mix space.
- `build.py`: Windows folder build with production assets. Rebuild after runtime changes and smoke-test the executable from a different working directory.
- Windows builds copy discovered content folders to external `paks/` beside the executable. Never compile/import launch Pak modules into the engine. `setup.py` preserves the same external folder hierarchy for Python installations. Check a newly added Pak against an already built executable, partial-only mixes, and no-Pak startup.
- `verify_distribution.py`: frozen solo smoke checks, a new ID/code/helper added after build, partial-only gameplay, empty/invalid-install screenshots and wheel layout assertions. It creates/removes its own known probe folder in the ignored distribution. The source verification/compatibility runners accept repeated `--pak-dir` options for isolated authoring checks.
- `new_pak.py`: non-overwriting starter generator. Copies selected component folders/assets and records their source; supports complete and partial API 4 Paks. Add future authoring helpers here rather than making runtime depend on generation services.
- [Asset authoring](assetforge/AGENTS.md): separate from runtime, with recorded provenance.
- `assetforge/local.py` + `run_audio.bat`: isolated official Stable Audio 3 installation, local batch generation and loopback-only studio. Pinned upstream revision and tested dependency lock; models/cache are ignored. Never install these dependencies into the game runtime.

Generated reports, screenshots, test profiles and build products belong in ignored `output/`, `build/` and `dist/`. Keep concise verified results in the wiki.

`verify_gamepad.py --frozen` runs gamepad_probe.py through the real SDL controller backend in source and the Windows executable. Its process-local SDL virtual pad navigates menus without assigning focus/calling actions, changes preferences/Pak selection, plays every solo Pak, pauses/resumes, disconnects/reconnects, tests focus loss and retries from defeat. Frozen QA loads its observer/helper from temporary external Paks, with no instrumentation shipped in the game. Requires the Windows Pygame SDL2.dll. Native API references: [virtual attach](https://wiki.libsdl.org/SDL2/SDL_JoystickAttachVirtual), [axis injection](https://wiki.libsdl.org/SDL2/SDL_JoystickSetVirtualAxis), [button injection](https://wiki.libsdl.org/SDL2/SDL_JoystickSetVirtualButton). This tests SDL events and polling, not a physical device/driver.

`verify_levels.py`: 360 cases across five seeds and levels 1/2/7/12/50/101. Checks repeatable fresh geometry, separate RNG, bounds and safe actor placements; exercises one second of advanced AI and renders levels 1/2/12 for every Pak. No survival assertion is made for late-level stress samples.

Expansion verification derives provider counts from discovery: 12^4 gameplay combinations, 12^2 presentation pairs, twelve solo/controller runs, and a dynamically sized level gallery. compatibility.py --case-file REPORT replays prior failure mixes into a separate report without replacing full-matrix evidence. Report actual gameplay checks separately from all six-role selection counts. New assets are exported by assetforge/export_expansion.py from per-Pak authoring metadata.

Mix compatibility now defaults to stability, not universal level clears. User explicitly permits ineffective combinations until a swap (for example Star Bastion pilot + Vector Coil weapon). --require-clear remains an opt-in balance probe; --seconds controls the sample duration. The full unit smoke matrix covers 20,736 gameplay mixes; native controller QA now checks shallow/full stick travel against all eight D-pad directions. Build wheels through setuptools.build_meta.build_wheel when sandbox pip metadata renames fail; build tooling remains separate from runtime.


- verify_platforms.py validates Sky Forge's authored graph links with the real pilot and ordinary double-jump/run inputs (no special). It searches jump timing, takeoff side and horizontal delay; outputs routes/failures separately from geometry-distance assumptions.
- powerup_probe.py / verify_powerups.py --frozen verify all twelve tenth-kill factories, exact spawn positions, once-only pickup, read-only rendering and upgrade retention after weapon/level changes. Frozen checks load a temporary external observer, never ship instrumentation. UI screenshots include UP before/after collection.
- Level/placement checks now use shape overlap/body filters. Connected racetrack rail bounding boxes intentionally overlap at joins; nonblocking hazards are not solid spawn exclusions. Keep rectangle-only overlap checks for plain Cover and test custom shapes with actual contacts/rays.
