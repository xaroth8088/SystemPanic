# Paper mantises

Local Mantis subclasses alternate curved approach and a 0.48s committed predictive dart. A wall unfolds a dart early. Movement/factory stats, bounded spawn placement, contact damage, level rewards and death feedback are local. Movement approaches a capped speed while health/contact damage continue growing with level. Eight authored bearing columns each contain four animation phases; velocity selects an upright pose without runtime rotation or mirroring. No spawning, family rules or attacks are interpreted by the host.


## True directional presentation

The current sheet uses 8 actual facing columns and four animation rows. East starts at column0; free-moving actors proceed clockwise through SE/S/SW/W/NW/N/NE, while Canopy uses East/West. Sprite selection uses the shared actor angle; sprite_angle returns zero and sprite_flip_x returns false. Original source poses and prior-row snapshots are recorded in pak.json authoring metadata and asset ledgers. Drawing must not mutate simulation or RNG.
