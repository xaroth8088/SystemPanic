# Bloom Siege: obstacles

Read [Pak memory](../AGENTS.md) and [Pak contracts](../../AGENTS.md).

Four permanent root gates regenerate by seed/level and repair overlaps as their width grows. Nectar geometry and refill rules now belong entirely to the weapon, so a copied weapon works with another obstacle provider. This component supplies no passive healing or automatic plant growth.

Assets/helpers stay inside this role. Sprite selection is read-only and uses the four-frame local row. Input devices and mapping belong to the shell. See [verification memory](../../../tests/AGENTS.md) for actual evidence and remaining limits.
