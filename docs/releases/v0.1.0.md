# System Panic v0.1.0

The first standalone release of System Panic: an offline, single-player arcade remix game with twenty-four complete Paks.

## Play on Windows

Download **SystemPanic-v0.1.0-windows-x64.zip**, extract the entire archive, and run **SystemPanic/SystemPanic.exe**. Keep `_internal/` and `paks/` beside the executable. No Python installation, account or network connection is required.

The Python wheel is an optional download for Python 3.12+ users. GitHub's automatically generated source archives are source code, rather than the standalone Windows game.

## Included

- Twenty-four games with their own pilot, enemies, weapon, music, background and procedural obstacles.
- Solo play, periodic component remixing, and a Static Remix builder with named local favorites.
- Endless levels: start with one enemy and face one more with each cleared level.
- Pak-owned collectible upgrades that survive weapon and level changes.
- Keyboard, mouse and SDL-mapped gamepad controls, including menu navigation.
- Local preferences and scores, display/audio settings and reduced-motion support.
- External complete or partial Paks that can be added without rebuilding the executable.

Original generated artwork and audio are included as finished local assets. The game never generates or downloads content. The distribution includes the asset provenance manifest; full provenance records and historical credits remain in the repository.

## Verification and scope

The release workflow runs ordinary regressions, all 331,776 gameplay component combinations, longer remix/swap and presentation checks, bounded solo/UI checks, frozen distribution checks, SDL virtual-controller checks and collectible checks. It also launches every complete Pak from a fresh ZIP extraction and from an isolated wheel installation. These are automated simulation and rendering checks, not physical hardware or human balance approval.

The Windows build is unsigned. Standalone Linux/macOS packages and custom controller remapping are not included in this release. Some component combinations are deliberately awkward until the next shuffle.

`SHA256SUMS.txt` contains SHA-256 hashes for the ZIP, wheel and `BUILDINFO.json`. `BUILDINFO.json` records the source commit, version and build toolchain. In PowerShell, use `Get-FileHash .\SystemPanic-v0.1.0-windows-x64.zip -Algorithm SHA256` and compare the result with the checksum file.
